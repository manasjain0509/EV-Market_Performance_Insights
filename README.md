# EV Market Performance & Insights

## Project Overview
This project focuses on analyzing Electric Vehicle (EV) market performance through interactive data visualizations and insights.

## Objectives
- Analyze EV sales by manufacturer.
- Compare annual sales across vehicle categories.
- Explore sales trends by model year.
- Understand battery technology distribution.
- Explore customer ratings and other EV market insights.
